\begin{abstract}
    En este proyecto vamos a gestionar y configurar dos redes de dos organizaciones distintas. Para ello, en cada una de las redes vamos a: interconectar los routers, asignar el direccionamiento y configurar las interfaces y protocolos de encaminamiento. Para finalizar, interconectaremos ambas organizaciones.
\end{abstract}
